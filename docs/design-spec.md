## 1. 品牌色彩系统

### 1.1 主色调

| 颜色名称 | 色值 | 用途 |
|---------|------|-----|
| 品牌橙 | `#ff8800` | 主按钮、激活状态、强调色 |
| 品牌黄 | `#ffaa00` | 渐变色、次要强调 |
| 金黄色 | `#ffcc00` | 渐变终止色、装饰 |

### 1.2 渐变色

```css
/* 主渐变 - 用于顶部导航、主按钮 */
background: linear-gradient(135deg, #ff9900, #ffcc00);

/* 按钮渐变 */
background: linear-gradient(90deg, #ff8800, #ffaa00);

/* 橙到黄水平渐变 */
background: linear-gradient(to right, #ff8800, #ffcc00);
```

### 1.3 功能色

| 颜色名称 | 色值 | 用途 |
|---------|------|-----|
| 成功绿 | `#52c41a` | 完成状态、上架状态 |
| 警告黄 | `#faad14` | 待处理、即将完成 |
| 危险红 | `#ff4d4f` | 加急订单、删除、拒绝 |
| 信息蓝 | `#1890ff` | 链接、信息提示 |

### 1.4 中性色

| 颜色名称 | 色值 | 用途 |
|---------|------|-----|
| 标题黑 | `#333333` | 主标题、重要文字 |
| 正文灰 | `#666666` | 正文、次要文字 |
| 辅助灰 | `#999999` | 占位符、禁用文字 |
| 边框灰 | `#e0e0e0` | 分割线、边框 |
| 背景灰 | `#f5f7fa` | 页面背景 |
| 卡片背景 | `#ffffff` | 卡片、模块背景 |

### 1.5 状态标签色

```css
/* 待审核 */
.status-pending { background-color: #fff7e6; color: #fa8c16; }

/* 已通过/制作中 */
.status-processing { background-color: #fff0e0; color: #ff8800; }

/* 已完成 */
.status-completed { background-color: #f6ffed; color: #52c41a; }

/* 加急/拒绝 */
.status-urgent { background-color: #fff1f0; color: #ff4d4f; }

/* 即将完成 */
.status-soon { background-color: #fcf4db; color: #faad14; }
```

### 7.1 基础动效

```css
/* 标准过渡 */
transition: all 0.3s ease;

/* 快速过渡 */
transition: all 0.2s ease;

/* 卡片悬停效果 */
.card:hover {
  transform: translateY(-4rpx);
  box-shadow: 0 16rpx 32rpx rgba(0, 0, 0, 0.1);
}

/* 按钮按下效果 */
.btn:active {
  transform: scale(0.98);
  opacity: 0.9;
}
```

### 7.2 加载动画

```css
/* 骨架屏渐变 */
@keyframes skeleton {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}

.skeleton {
  background: linear-gradient(90deg, #f0f0f0 25%, #e0e0e0 50%, #f0f0f0 75%);
  background-size: 200% 100%;
  animation: skeleton 1.5s infinite;
}
```

### 7.3 页面转场

- 进入: 从右侧滑入 (300ms)
- 返回: 向右滑出 (300ms)
- 弹窗: 从底部滑入 + 遮罩渐显
