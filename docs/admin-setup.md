# 管理员权限设置说明

## 权限控制机制

系统通过数据库中用户的 `isAdmin` 字段来判断用户是否为管理员。

## 设置管理员的方法

### 方法1: 通过小程序界面（推荐）

1. 用户在个人中心页面连续点击用户ID **5次**
2. 会弹出管理员登录对话框
3. 输入管理员密码（默认: `123456`）
4. 验证成功后，该用户会被标记为管理员
5. 管理员入口按钮会显示出来

### 方法2: 直接在数据库中设置

1. 打开微信开发者工具
2. 进入云开发控制台
3. 打开数据库 → `users` 集合
4. 找到目标用户记录
5. 编辑该记录，添加或修改字段：
   ```json
   {
     "isAdmin": true
   }
   ```
6. 保存后，该用户重新登录即可看到管理员入口

## 权限验证

### 登录时验证
- 用户登录时，系统会从数据库读取 `isAdmin` 字段
- 如果用户是新注册用户，默认 `isAdmin` 为 `false`
- 如果用户已存在，会保留原有的 `isAdmin` 状态

### 进入管理后台时验证
- 点击"进入管理后台"按钮时，系统会检查 `isAdmin` 字段
- 如果不是管理员，会弹出"权限不足"提示
- 只有 `isAdmin` 为 `true` 的用户才能进入管理后台

## 修改管理员密码

管理员密码存储在云函数中，修改步骤：

1. 打开文件：`cloudfunctions/adminAuth/index.js`
2. 修改第10行的密码：
   ```javascript
   const ADMIN_PASSWORD = '你的新密码'
   ```
3. 重新上传云函数

## 安全建议

1. **修改默认密码**: 部署到生产环境前，务必修改默认的管理员密码
2. **密码强度**: 使用强密码（包含大小写字母、数字、特殊字符）
3. **定期更换**: 定期更换管理员密码
4. **权限审计**: 定期检查数据库中的管理员账号，移除不再需要的管理员权限
5. **日志记录**: 建议在云函数中添加管理员操作日志

## 移除管理员权限

### 方法1: 通过数据库
1. 打开云开发控制台
2. 进入 `users` 集合
3. 找到目标用户，将 `isAdmin` 改为 `false` 或删除该字段

### 方法2: 创建管理员管理页面（建议）
在管理后台添加用户管理功能，可以：
- 查看所有用户列表
- 设置/取消管理员权限
- 查看管理员操作日志
