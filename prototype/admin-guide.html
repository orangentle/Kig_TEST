核心功能 · 6 项

管理后台围绕"千级订单"场景设计，支持分页加载、多维筛选、批量操作。
所有写操作通过云函数 batchUpdateOrders 校验管理员权限，操作日志写入 updateTime。

1
概览卡 点击即筛选
顶部 7 张统计卡显示订单总数、待审核、制作中、加急、逾期、已完成、已归档。
使用：点任意一张卡 → 自动切换对应 tab/筛选条件
例：点"加急" → 列表只显示 isUrgent=true 的订单
2
搜索 + 筛选 + 排序
支持模糊搜索订单号/客户/角色；按下单日期筛选；多维排序。
搜索：顶部搜索框输入 → 回车
排序："排序"按钮 → 最新下单 / 即将到期 / 进度靠前/后
筛选："筛选"按钮 → 起止日期 / 是否包含已归档
3
阶段标签 12 个 tab
全部 / 待审核 / 加急 / 逾期 + 8 个制作阶段（订单确认 → 发货）。
使用：横滑切换 tab → 列表实时刷新
分页：每页 20 条，下滑触底自动加载更多
4
多选 + 批量操作 核心
点"多选"或长按任一订单进入多选模式。批量操作单次最多 500 条。
进入多选：顶部"多选"按钮 / 长按订单卡
勾选订单：点卡片左侧圆点 / 点"全选本页"
批量操作（底部浮窗）：
　• 推进阶段 — 把所选订单各自往下一阶段推一格
　• 设为阶段 — 指定阶段（如全部设到"打印中"）
　• 设/取消加急 — 切换 isUrgent + status
　• 分配排单号 — 自动生成 RatStudio-2026-NNN 序列
　• 归档 — 从主列表移除（不删除数据）
5
单订单操作
非多选模式下，点订单卡进入详情页，可单独修改字段、查看历史。
点订单：跳转到订单详情（admin 模式，含编辑入口）
色条：灰=普通 / 红=加急 / 黄=待审 / 绿=完成
6
新增订单 + 审核 + 作品 + 导出
右上角"+"按钮打开操作菜单。
新增订单：表单填写淘宝单号/客户/角色/截止日期/预览图
订单审核：跳转待审核订单专属页
作品管理：跳转完成作品维护页
导出数据：Excel 导出（开发中）
⚡ 性能 & 安全

列表分页 20 条/页 + 复合索引（isArchived+stage+createTime）支撑千级订单秒级响应。
所有批量写操作经云函数 batchUpdateOrders 校验：仅 users 集合中 isAdmin=true 的账号可调用。
