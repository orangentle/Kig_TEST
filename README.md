## 项目简介

鼠鼠工坊微信小程序是为专注于Kigurumi头壳制作的工作室开发的订单管理与进度追踪平台。该小程序为客户提供了便捷的订单查询和制作进度跟踪功能，让客户可以随时了解自己定制头壳的制作状态。

PS：云端的envId随便写的测试用环境，字段、订单也是ai随便写的，仅供参考。

## 功能特点

- **订单查询**：通过淘宝订单号快速查询头壳制作进度
- **进度追踪**：直观的进度条展示当前制作阶段
- **个人中心**：登录后查看个人所有订单列表
- **微信登录**：支持一键微信授权登录
- **云开发功能**：使用微信云开发实现数据管理和订单处理

## 制作流程

头壳制作流程对外展示 **5 个阶段**：

1. 已排单（订单确认 + 排队中）
2. 建模（3D 建模 + 打印）
3. 上妆（打磨 + 喷漆 + 细节处理）
4. 假毛（毛发种植 + 造型）
5. 已发货（质检后发出）

> **待沟通事项（与客户/工坊负责人确认后再细化）：**
> - 是否需要在管理后台增加 **内部子状态**（`subStage`）以便更精细地追踪进度
>   - 建议拆分示例：建模 → 3D 建模 / 打印；上妆 → 打磨 / 喷漆
>   - 对外仍展示 5 阶段，仅管理后台可见 `subStage`
> - 是否需要 **客户留言 / 订单评论时间线**（当前版本不做，仅展示当前阶段）
> - **发货提醒**（订阅消息）当前为简易实现，后续补充：物流单号录入、自动推送模板等

## 下单表单字段

客户在下单页填写以下信息（提交后自动锁定，需联系客服解锁修改）：

- **身体尺寸**：身高 / 体重 / 头围 / 肩宽
- **角色信息**：角色名 / 角色所属 IP / 多视角参考图（最多 3 张）
- **配饰需求**：是否需要配饰
- **替换脸**：是否需要 + 数量（1-3 张），每张脸上传 1 张表情参考图
- **加急**：+1200 元（当前价格）

## 项目结构

```
miniprogram/
  ├── app.json          # 全局配置
  ├── app.ts            # 应用入口
  ├── app.wxss          # 全局样式
  ├── assets/           # 静态资源
  │   ├── icons/        # 图标资源（包含导航栏图标）
  │   └── images/       # 图片资源
  ├── pages/            # 页面文件
  │   ├── index/        # 首页（订单查询）
  │   ├── logs/         # 日志页面
  │   ├── order-detail/ # 订单详情页
  │   ├── profile/      # 个人中心
  │   └── webview/      # 网页视图（用于打开外部链接）
  ├── miniprogram_npm/  # 小程序依赖包
  └── utils/            # 工具函数

cloudfunctions/
  ├── adminAuth/        # 管理员身份验证
  ├── createOrder/      # 创建订单
  ├── getOpenId/        # 获取用户OpenID
  ├── getOrders/        # 获取订单列表
  ├── initOrderData/    # 初始化订单数据
  ├── login/            # 用户登录
  └── updateAvatar/     # 更新用户头像
```

## 原型设计

prototype/

## 安装与运行

1. 克隆仓库
```bash
git clone https://github.com/your-username/ratstudio-miniprogram.git
```

2. 使用微信开发者工具打开项目

3. 在微信开发者工具中导入项目，选择项目根目录

4. 编译运行
